# Кузня Миров

| Папка | Что в ней |
| --- | --- |
| `games/` | Готовые данные игр. Например, «Орда» — `games/horde/`, «Распутье» — `games/platformer/`, «Яма» — `games/pit/`. Список игр на главной хранится в `games/index.json`. |
| `games/recording-scenes/` | Проекты для записи роликов. Ищите по префиксам `video-ep3-`, `video-fight-`, `video-jump-` и `video-editor-`. Сцену можно открыть в редакторе по имени её папки, например `/editor.html?project=video-ep3-heroes`. |
| `art/` | Исходные материалы по играм. Земля «Ямы» и скрипты её сборки в `art/pit/ground/`, исходники движений зомби в `art/pit/animations/`. В `art/village/` отдельно лежат земля, небо, задний план, постройки, предметы и растительность. |
| `engine/` | Код и тесты движка. В `engine/vendor/` находятся локальные копии Lua-исполнителя `luars` и библиотеки текста `cosmic-text`. |
| `web/` | Страница игр, редактор и их сборка. |
| `importer/` | Служба подготовки текстур и моделей. Обработанные файлы появляются в `imported/` внутри проекта игры. |
| `tools/` | Скрипты для графики, города, штампов рельефа и обслуживания сборок. |
| `deploy/` | Настройки nginx. Команда `docker compose up --build` запускается из корня. |

Для локального запуска игр и редактора используйте `npm install`, затем `npm run dev` в `web/`.
