## Фича: базовый минимум движка «Кузня Миров»

### Цель

Движок, который читает описание игры из файлов и играет её в браузере. Проверяется тем, что на нём
собираются две непохожие игры — змейка и арканоид — правкой данных, без единого изменения в коде
движка.

### Scope

**В рамках:** ядро (объекты рядами, круг из девяти этапов), чтение и предстартовая проверка четырёх
файлов игры, четыре вида правил, поиск пересечений, отрисовка цветных прямоугольников через `wgpu`,
клавиатура, сборка в WebAssembly, страница-обёртка, две демо-игры.

**Вне scope:** картинки, редактор, React, звук, публикация по ссылке, запись и повтор партий,
скрипты, сглаживание движения между шагами, поколения объектов, трёхмерность, сохранение прогресса
игрока, сеть, показ счёта на экране.

### Функциональные требования

1. Страница берёт папку игры по HTTP рядом со сборкой (`/games/snake/`) и читает `game.json`,
   `properties.json`, `scene.json`, `rules.json`.
2. Предстартовая проверка собирает **все** ошибки за один заход; каждая называет файл, объект или
   правило и суть проблемы. При любой ошибке игра не запускается.
3. Все значения вида `time` переводятся в шаги при загрузке как `округление(секунды × 60)`, минимум
   один шаг. Внутри игры секунд не существует. Перевод касается `lifetime`, `grid.interval`,
   авторских свойств, объявленных видом `time`, и постоянных внутри действий над ними.
4. Свойства хранятся рядами, объект — номер, у каждого свойства отметка присутствия.
5. Круг из девяти этапов дословно по «Исполнению игры»; внутри этапа правила идут в порядке файла.
6. Четыре вида правил (подвинуть, столкнуть, удалить, создать) со своими условиями и действиями.
7. Пересечения: равномерная сетка только по объектам с `collides`, размер ячейки по крупнейшему из
   них, касание ровно по границе пересечением не считается, пары сортируются по номерам.
8. Отскок: разворот скорости по оси меньшего перекрытия и выталкивание наружу на его величину; один
   отскок на объект за шаг, прочие действия правила при этом выполняются.
9. Отрисовка: цветные прямоугольники, всё однотипное уходит одной командой, порядок по `layer`,
   затем по номеру объекта.
10. Ввод: события нажатия и отпускания, применяются на втором этапе; при догоняющих шагах достаются
    первому шагу серии, остальные шаги серии видят пустой ввод.
11. `end_game` останавливает шаги, последний кадр остаётся на экране; перезапуск — перезагрузка
    страницы.
12. `image` в данных — ошибка предстартовой проверки с текстом «картинки в этой версии не
    поддержаны».
13. Демо-игры `games/snake/` и `games/arkanoid/` из документации играются обе.

### Edge cases и обработка ошибок

- Битый JSON: ошибка с именем файла и позицией, старта нет.
- Неизвестный вид правила, недостающая настройка, значение не того вида: в общий список ошибок.
- Объекту под правилом не хватает свойства для действия: ошибка. Прибавка внутри `effects`
  проверяется на отобранных объектах; прибавка в `do` адресована всем носителям свойства, ей
  довольно, чтобы свойство было объявлено и встречалось хоть у одного объекта.
- Нет свободной клетки для `random_cell`: заявка на создание отброшена, сообщение один раз.
- Достигнут `max_objects`: заявки на создание отбрасываются, сообщение один раз.
- Просадка машины: не больше пяти догоняющих шагов, остаток копилки времени сбрасывается.
- Вкладка была скрыта: копилка обнуляется, разрыв не догоняется.
- Потеря контекста видеокарты: поверхность пересоздаётся, состояние мира не трогается.
- WebGPU недоступен: откат на WebGL2; нет и его — сообщение на странице вместо игры.

### Технические детали

- **Репозиторий:** `C:\projects\kuznya-mirov`, remote `git@github.com:lopatuxin/kuznya-mirov.git`.
- **Папки:** `engine/` (Rust), `web/` (страница), `games/snake/`, `games/arkanoid/`, `docs/plans/`.
- **Библиотеки:** `wgpu` (ветка 29.x — точную стабильную версию сверить при `cargo add`),
  `wasm-bindgen`, `web-sys` (canvas, клавиатура, fetch), `serde` + `serde_json`.
- **`winit` не нужен:** поверхность создаётся прямо из `HtmlCanvasElement` через
  `SurfaceTarget::Canvas` — подтверждено текущей документацией wgpu.
- **Сборка:** цель `wasm32-unknown-unknown`, упаковка `wasm-pack`. Страница — минимальный
  `index.html` с холстом и модулем-загрузчиком, dev-сервер Vite. React в этой версии не нужен.
- **Схема данных:** файлы игры по «Формату игры», миграций нет.
- **API:** нет; весь обмен — чтение файлов игры по HTTP.
- **UI:** один холст во весь экран.

### Non-functional

- Кадр не должен проседать от числа объектов на типичной сцене: всё однотипное уходит одной
  командой видеокарте.
- Сообщения об ошибках на русском.
- `max_objects` по умолчанию 10 000.

### План реализации

1. Репозиторий, `CLAUDE.md` кода, каркас папок, сборка Rust в WebAssembly, пустая страница с
   холстом.
2. Отрисовка: залить холст и нарисовать один прямоугольник через `wgpu`, откат на WebGL2.
3. Хранение объектов рядами и чтение `scene.json`; сцена рисуется статично, без правил.
4. Предстартовая проверка и перевод времени в шаги.
5. Круг из девяти этапов вхолостую: копилка времени, счётчики жизни, счётчик хода по клеткам.
6. Правило «подвинуть»: непрерывное движение и движение по клеткам.
7. Клавиатура: нажатие и отпускание, очередь ввода, применение на втором этапе.
8. Поиск пересечений равномерной сеткой.
9. Правила «столкнуть», «создать», «удалить»; заявки, их исполнение на границе шага, конец игры.
10. Демо-змейка целиком: играется от начала до проигрыша.
11. Отскок и демо-арканоид: играется, есть и проигрыш, и победа.
12. Пакетная отрисовка одной командой, порядок по слоям.

### Тесты

- Перевод секунд в шаги: округление и минимум один шаг.
- Предстартовая проверка: каждая категория ошибок даёт сообщение; ошибки собираются все сразу, а не
  по первой.
- Пересечение прямоугольников: касание ровно по границе не считается пересечением.
- Порядок этапов: объект, созданный на шаге N, впервые виден на шаге N+1; удаления исполняются
  раньше созданий.
- Змейка: прогон известного числа шагов на демо-данных даёт ожидаемую длину следа и не заканчивается
  раньше времени.
- Арканоид: мяч разворачивается по нужной оси и выталкивается наружу; за шаг отскакивает один раз.
- Потолок объектов и отсутствие свободной клетки для `random_cell`.
